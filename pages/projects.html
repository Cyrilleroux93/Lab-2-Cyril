My Projects

Here are three projects I have worked on. They are quite different from each other, but all three involved learning something new and trying things I had not done before.

Change Management E-learning

I created this e-learning because I wanted to become more familiar with Articulate Storyline. I also wanted to experiment with ChatGPT and see how good or bad it would be at helping to create learning content.

I deliberately picked change management because it was a topic I did not know particularly well. Part of the experiment was to see if I could build something useful without already being an expert on the subject.

The main challenge was checking the content rather than simply accepting everything that was generated. It also took some time to understand how Storyline worked and how I wanted the different parts of the course to interact.

I think the end result turned out quite well, especially considering that it was mainly an experiment to learn the software.

Try the Change Management e-learning

Innovation Leadership Simulation

The company I currently work for specialises in business simulations. A few years ago some colleagues tried to create a program around innovation leadership, but the project did not really work out. I wanted to have a go at the idea myself.

This time I wanted to use Articulate 360 for something different from a normal e-learning. The idea was to create an interactive simulation where participants act as consultants to a company going through different changes and have to make decisions along the way.

This was much more difficult and time consuming than the change management e-learning. There were more things happening at the same time and the different decisions needed to feel connected to each other.

I only completed a few of the challenges, but the project helped me understand much more about what could be done with the software and also where its limitations were.

This Portfolio

The last project is this website. Before starting this course I was completely new to HTML and CSS, so building the portfolio has involved quite a lot of trial and error.

One of the main challenges has been understanding how the different parts of CSS affect each other. Something that looks right on a laptop does not necessarily work properly on a phone, so I have had to go back and change things several times.

I have also tried to reuse the same CSS classes across the different pages rather than creating new styles for every page. This has made more sense as the website has grown and has made it easier to keep the design consistent.
