# Interactive Portfolio Website - Grade 3

This project is a personal portfolio website that I created as part of my web development course. The website uses HTML, CSS, and JavaScript. The goal is to have a website where I can share some information about myself, my skills, and the projects I have worked on.

I started working on this website during Lab 1. The main focus was to create the different pages, add the content, and use CSS to make the website look good. I also worked on making the website responsive so that it can be used on computers, tablets, and phones.

For Lab 2, I continued working on the same website, but this time with more focus on JavaScript. The goal was to make the website more interactive and learn how JavaScript can work together with HTML and CSS. One of the main things I worked on was a feedback form where visitors can enter their information and get messages if something is missing or incorrect.

During this project, I tried to keep things simple and reuse as much of my previous code as possible. I also learned more about how to test my website, find and fix problems, and use Git and GitHub to save my work and keep track of the changes I made.

## Features

The website has several pages that visitors can access using the navigation bar. These include a home page, an about page, a projects page, a skills page, a contact page, and a feedback page.

The website also has a responsive design, which means that the layout changes depending on the size of the screen.

For Lab 2, I added a feedback form using JavaScript. Visitors can enter their name, email address, select a topic, write comments, and optionally add a website address.

The form checks the information entered by the visitor and shows error messages when something is incorrect or missing. It also has a character counter for the comments field, a success message when the form is completed correctly, and a button to clear the form.

## Testing and Results

I tested the website to make sure that the different pages and the feedback form work correctly. I also checked how the website looks and works on different screen sizes.

The main things I tested were:

- Navigation:** Checked that the links between the different pages work correctly.
- Responsive design:** Tested the website on desktop, tablet, and mobile screen sizes.
- Form validation:** Tested the different fields with correct, incorrect, and missing information to make sure the error messages appear when needed.
- Character counter:** Checked that the counter updates when typing and that the color changes depending on the number of characters.
- Submit and Clear buttons:** Checked that the success message appears when the form is completed correctly and that the Clear button resets the form.
